# 628. Maximum Product of Three Numbers

## Problem

Given an integer array `nums`, return the maximum product that can be obtained from any three numbers.

---

## Approach

- Sort the array.
- The maximum product can come from:
  - The three largest numbers.
  - The two smallest (negative) numbers and the largest positive number.
- Return the maximum of these two products.

---

## Algorithm

1. Sort the array.
2. Calculate the product of the last three elements.
3. Calculate the product of the first two elements and the last element.
4. Return the larger product.

---

## Complexity

- **Time Complexity:** `O(n log n)`
- **Space Complexity:** `O(1)`

---

## Concepts Used

- Arrays
- Sorting
- Math
