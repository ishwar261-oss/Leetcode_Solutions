# 16. 3Sum Closest

## Problem

Given an integer array `nums` and an integer `target`, find three integers in the array whose sum is closest to the target.

Return the sum of the three integers.

---

## Approach

- Sort the array.
- Fix one element and use two pointers to search for the best pair.
- Calculate the current sum.
- If it is closer to the target than the previous answer, update the answer.
- Move the pointers based on whether the sum is smaller or larger than the target.
- If the sum equals the target, return it immediately.

---

## Algorithm

1. Sort the array.
2. Initialize the answer using the first three elements.
3. For each index:
   - Fix one element.
   - Use two pointers to calculate the closest sum.
4. Update the answer whenever a closer sum is found.
5. Return the final answer.

---

## Complexity

- **Time Complexity:** `O(n²)`
- **Space Complexity:** `O(1)`

---

## Concepts Used

- Sorting
- Two Pointers
- Arrays

---
