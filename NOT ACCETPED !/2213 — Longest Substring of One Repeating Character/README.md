# LeetCode 2213 — Longest Substring of One Repeating Character

## Problem

You are given a string `s`.

There are multiple queries. Each query changes one character of the string.

After every change, find the length of the **longest substring containing only the same character**.

A substring must contain **continuous characters**.

---

## Example

```text
s = "babacc"

queryCharacters = "bcb"
queryIndices = [1, 3, 3]
